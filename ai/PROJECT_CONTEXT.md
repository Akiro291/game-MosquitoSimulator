# Mosquito Simulator — Project Context

Канонический короткий дизайн: `ai/GDD.md`. Этот файл — сжатый контекст для агента.

## Краткое описание

Mosquito Simulator — игра от третьего лица/с камерой вокруг маленького комара в небольшом дачном/коттеджном поселке.

Ключевая идея:

> Для человека комар — мелкая раздражающая дрянь.
> Для комара человек — огромный опасный NPC.

Размер и масштаб мира должны ощущаться физически и визуально.

## Основной игровой цикл

1. Летать.
2. Искать взрослого человека.
3. Подлетать незаметно.
4. Сесть на человека.
5. Пить кровь.
6. Не попасться.
7. Улeтеть.
8. Выживать.
9. Размножаться.
10. Получать улучшения.
11. Создавать следующие поколения.
12. Адаптироваться к более опасным зонам.

## Главные системы

### Комар

- полет;
- скорость;
- энергия;
- запас крови;
- голод;
- заметность;
- шум/жужжание;
- обнаружение;
- повреждение крыльев;
- постепенное визуальное увеличение брюшка после крови.

### Человек

Состояния:

- Calm;
- Noticed;
- Irritated;
- Angry;
- Chase.

Человек должен иметь собственную активность и в будущем расписание.

### Укус и кровь

Кровь должна быть не просто очками:

- расходуется;
- поддерживает выживание;
- нужна для размножения;
- используется для прогрессии.

### Погоня

Раздражение человека может перейти в Chase Mode.

Погоня — отдельная игровая активность:

- игрок провоцирует человека;
- человек пытается убить комара;
- игрок выживает;
- длительность погони приносит награду;
- потеря человека завершает погоню.

### Стелс

Потенциальные параметры:

- Noise;
- Visibility;
- Scent/Heat.

Быстрый полет может быть громче.

Медленный полет — тише, но занимает больше времени.

### Mosquito Sense

Специальный режим восприятия, позволяющий искать человека по:

- CO2;
- запаху;
- теплу.

Это одна из фирменных механик проекта.

### День и ночь

День:

- больше людей на улице;
- высокая активность;
- комаров легче заметить.

Ночь:

- больше людей внутри домов;
- охота может быть проще;
- появляются ночные опасности.

### Хищники

Постепенно:

- пауки;
- лягушки;
- стрекозы;
- птицы;
- летучие мыши;
- рыбы/опасности около воды.

Не добавлять всех сразу.

### Вода и размножение

Потенциальные места:

- лужи;
- ведра;
- бассейн;
- фонтан;
- пруд;
- цветочные горшки;
- бочки;
- другие емкости с водой.

Дождь должен менять доступные места размножения.

### Погода

Позже:

- дождь;
- ветер;
- жара;
- холод;
- туман.

Ветер должен физически влиять на маленького комара.

### Генетика

Игрок — самка комара.

Кровь → яйца → место кладки → личинки → новое поколение.

Следующее поколение наследует часть характеристик.

Потенциальные характеристики:

- скорость;
- дальность полета;
- скрытность;
- устойчивость;
- запас крови;
- эффективность укуса;
- сопротивление ветру.

## NPC

Взрослые люди — полноценные NPC, а не статичные манекены.

В будущем у каждого может быть:

- собственный распорядок;
- занятия;
- маршрут;
- реакция на комара;
- индивидуальные параметры.

Детей можно использовать как обычных NPC, но они не должны быть целями для укусов.

## Юмор и поздние системы

После основной механики можно добавить:

- комариную цивилизацию;
- торговцев;
- скаутов;
- фонд голодающих комариков;
- экипировку;
- необычные предметы;
- фракции;
- репутацию;
- абсурдные задания.

Это второй слой игры, а не MVP.

## Визуальный принцип

Не требуется сразу делать графику уровня AAA.

Лучше:

- маленький качественный участок;
- один хороший дом;
- хорошая трава;
- освещение;
- несколько NPC;
- качественное ощущение масштаба.

Если вертикальный срез работает и ощущается интересно — расширять мир.
