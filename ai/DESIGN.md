# Mosquito Simulator — Уточнённый Game Design Document (v1.1)

## 1. Высокоуровневая концепция

**Жанр:** 3D Survival / Stealth / Simulator с элементами Evolution и Comedy.

**Игрок:** самка комара (≈ 1–2 см) в небольшом дачном/коттеджном посёлке.

**Ключевое ощущение:**
> Для человека комар — мелкая раздражающая дрянь.  
> Для комара человек — гигантский опасный босс.

Масштаб должен читаться **телом камеры и физикой**, а не только визуалом.

**Главный цикл:**
Охота → Кровь → Выживание → Риск → Погоня → Награда → Размножение → Эволюция.

Юмор (фонд голодающих комариков, экипировка, комариная цивилизация) — **второй слой**, который появляется только после того, как основная петля уже работает и приносит удовольствие.

---

## 2. Масштаб (фундамент игры)

**1 uu = 1 cm**

| Объект          | Размер (примерно) | Ощущение для игрока      |
|-----------------|-------------------|--------------------------|
| Комар           | 1–2 см            | Игрок                    |
| Травинка        | сопоставима       | Укрытие / препятствие    |
| Стакан          | ~15 см            | Башня                    |
| Стол            | ~75 см            | Плато                    |
| Кошка           | огромная          | Хищник-босс              |
| Человек         | 170–190 см        | Гигантский босс          |

Камера близкая, near-clip маленький. Мир должен ощущаться огромным даже на примитивах.

## 3. Основные системы (по приоритету)

### 3.1. Комар — характеристики

| Параметр        | Роль |
|-----------------|------|
| Health          | Живучесть |
| WingCondition   | 0–100. Урон по крыльям сильно снижает скорость и манёвренность |
| Blood           | Ресурс выживания + топливо для яиц и прогрессии. Тратится со временем |
| Hunger          | Растёт без крови |
| Energy          | Полёт, спринт, долгая охота |
| FlightSpeed     | Базовая скорость |
| Noise           | Жужжание (быстрый полёт = громче) |
| Visibility      | Насколько легко увидеть |
| Scent / Heat    | Заготовка под Mosquito Sense |

После сытого укуса брюшко визуально толстеет → манёвренность падает (визуал после MVP).

### 3.2. Кровь (вдохновение V Rising + твоя идея)

Кровь — не просто «очки».

**Базовая механика (MVP + 0.2):**
- Есть запас крови.
- Она тратится на жизнь.
- Нужна для яиц и улучшений.

**Расширение (0.3+):**
Разные типы крови дают временные бонусы (как blood types в V Rising):

| Тип крови     | Источник                  | Бонус (пример)                  |
|---------------|---------------------------|---------------------------------|
| Обычная       | Средний взрослый          | Нет особого                   |
| Спортивная    | После тренировки          | +скорость / +энергия          |
| Пожилая       | Пожилой человек           | +скрытность                   |
| «Сладкая»     | После еды/алкоголя        | +макс. запас крови            |
| Репеллент     | Человек в репелленте      | Почти бесполезна / штраф      |

Качество крови (процент) может усиливать бонус (простая 3-уровневая система вместо 5 тиров V Rising).

Игрок сам выбирает, кого кусать ради нужного эффекта.

### 3.3. Человек — состояния раздражения

| Уровень | Состояние   | Поведение |
|---------|-------------|---------|
| 0       | Calm        | Занятие / idle |
| 1       | Noticed     | «Чёрт, комар» — может хлопнуть |
| 2       | Irritated   | Чешется, чаще машет |
| 3       | Angry       | Активно ищет |
| 4       | Rage/Chase  | Бросает занятие, охотится |

Источники раздражения: укус, близость, громкое жужжание у головы.  
Если комар далеко — раздражение медленно падает.

### 3.4. Погоня (фирменная механика)

Отдельная мини-игра риска:

- Вход в Chase → таймер.
- Время в погоне = очки (10с=10, 30с=50, 60с=150, 120с=500).
- Выход: комар потерян → Chase Complete + награда.

Позже эскалация: мухобойка, второй человек, закрытие окон, предугадывание полёта.

Игрок может **специально** жужжать у уха, чтобы ускорить ярость ради больших очков («комар-террорист»).

### 3.5. Две стратегии игрока

**Тихий комар:**  
Скрытность → посадка → укус → уйти незаметно.

**Комар-террорист:**  
Жужжание → укусы → ярость → погоня → выжить → большая награда.

Один и тот же NPC даёт разный геймплей.

### 3.6. Стелс и Mosquito Sense

Три канала: Noise, Visibility, Scent/Heat.

**Mosquito Sense** (фирменная механика):
Режим восприятия по CO₂ / теплу / запаху. Позволяет искать жертву без прямой видимости.

### 3.7. День / Ночь

Обязательно уже в 0.1.

- День: люди активны, выше шанс быть замеченным.
- Ночь: люди в домах/спят, охота проще, позже появляются ночные хищники.

Длина суток в MVP короткая (2–5 минут = сутки) для быстрой проверки цикла.

## 4. Смерть и поколения (вдохновение Spore)

**MVP 0.1:**  
Смерть → короткий респавн (уже почти сделано).

**Целевая модель (0.3):**
Игрок — самка.  
Кровь → яйца → место кладки (вода) → личинки → новое поколение.

При создании нового поколения игрок выбирает уклон (как в Spore Creature Stage, но сильно упрощённо):

- Скорость
- Скрытность
- Запас крови
- Эффективность укуса
- Устойчивость к ветру / повреждениям крыльев

Новый комар наследует часть характеристик предыдущего.  
Смерть не обнуляет прогресс — линия продолжается.

Это даёт долгосрочную мотивацию и ощущение «эволюционной линии».

## 5. Мир и опасности (по версиям)

**MVP 0.1:**  
Маленький двор + 1 дом (блокаут) + 2–3 взрослых + день/ночь + хлопок.

**0.2:**  
Погоня с очками, паук + паутина (зона страха), сейв, простой UI, базовая прокачка.

**0.3:**  
Вода + кладка яиц + поколения + генетика.

**0.4:**  
Небольшой посёлок, расписания NPC, дома с интерьерами, погода, ветер, дополнительные хищники.

**0.5+:**  
Экипировка, комариные NPC, фонд голодающих комариков, юмор, задания, фракции, районы.

## 6. Что брать из других игр (и как адаптировать)

| Игра          | Что берём                              | Как адаптируем под Mosquito Simulator |
|---------------|----------------------------------------|---------------------------------------|
| **V Rising**  | Blood Types + качество крови + бонусы | Упрощённая система типов крови взрослых людей + временные баффы |

| **Metamorphosis** | Мир с точки зрения крошечного существа | Акцент на «стол = плато», «стакан = башня» |

## 7. Definition of Done по версиям (чётко)

### Version 0.1 (сейчас)
Игрок может:
1. Управлять комаром
2. Летать по маленькому двору
3. Найти 2–3 взрослых
4. Сесть и укусить
5. Вызвать цепочку раздражения до Chase
6. Получить урон крыльям / умереть
7. Увидеть базовый HUD
8. Респавниться

**Гейт:** «На примитивах уже весело и страшновато играть 10–15 минут».

### Version 0.2
+ Chase Score, паук, сейв, простой UI, базовая прокачка.

### Version 0.3
+ Вода, яйца, поколения, наследование характеристик.

И так далее.

---

## 8. Принципы разработки (очень важно)

1. **Сначала fun на примитивах** — потом графика.
2. Один вертикальный срез за раз.
3. Не добавлять системы из 0.3–0.5, пока 0.1 не прошёл плейтест-гейт.
4. Все числа баланса выносить в `UPROPERTY` / Data Assets как можно раньше.
5. Юмор и «комариная цивилизация» — только после того, как основная петля работает.
