# Mosquito Simulator — Game Design Document (short)

Рабочий документ для разработки. Не фичалист на 3 года: здесь зафиксированы ощущение игры, правила систем и границы MVP.

---

## 1. Что это за игра

**Жанр:** 3D survival / simulator со stealth, evolution и comedy.

**Игрок:** самка комара (~1–2 см) в дачном/коттеджном поселке.

**Ощущение:** для человека комар — мелкая дрянь; для комара человек — гигантский опасный NPC. Масштаб должен читаться телом камеры: травинка ≈ комар, стол — плато, стакан — башня, человек — босс.

**Главный цикл:** охота → кровь → выживание → риск → погоня → награда → размножение → эволюция.

Юмор (фонд голодающих комариков, экипировка, комариная цивилизация) — второй слой после рабочей охоты.

---

## 2. Масштаб (Unreal)

1 uu = 1 cm.

| Объект | Ориентир |
| --- | --- |
| Комар | 1–2 cm, капсула ~0.5 radius / 1.0 half-height |
| Травинка | сопоставима с комаром |
| Стол | ~75 cm высота = плато |
| Стакан | ~15 cm = башня |
| Кошка | огромный хищник |
| Человек | ~170–190 cm = босс |

Камера близкая, мир читается снизу. Не гнаться за графикой GTA: один качественный дом, трава, свет, 2–3 человека.

---

## 3. Сущности (MVP и позже)

**MVP**

- Игрок-комар
- 2–3 взрослых человека
- Небольшой двор + 1 дом (blockout)
- Солнце / день-ночь
- Воздушная атака человека (хлопок)

**Позже, по версиям**

- Паук и паутина, другие хищники
- Вода / кладки
- Поколения
- Погода и ветер
- Расписания NPC, сетки на окнах, свет в комнатах

**Не цель для укуса:** дети. Могут быть в мире как NPC, охота только на взрослых.

---

## 4. Комар — характеристики

Все числа ниже — стартовый баланс, вынести в `UPROPERTY`.

| Параметр | Роль |
| --- | --- |
| Health | живучесть; 0 = смерть |
| WingCondition | 0–100; урон по крыльям снижает скорость |
| Blood | ресурс выживания / (позже) яиц и прогрессии; тратится со временем |
| Hunger | растёт без крови |
| Energy | полёт, спринт, долгая охота |
| FlightSpeed | базовая скорость |
| Noise | жужжание; быстрый полёт громче |
| Visibility | насколько легко увидеть |
| Scent / Heat signature | насколько комар «виден» теплом/CO₂ (заготовка) |

После сытого укуса брюшко визуально толстеет и манёвренность падает (визуал можно после MVP-логики).

Игрок сам выбирает стиль:

- **Тихий:** медленный подход, укус, уйти незаметно.
- **Террорист:** жужжать у уха, бесить, устраивать погоню ради очков.

---

## 5. Полёт

- Свободный 3D полёт (не ходьба по земле как основной режим).
- Небольшая инерция: комар лёгкий.
- Быстрее = громче = проще обнаружить.
- Медленнее = тише, но дольше на линии огня.
- Ветер (не MVP) реально сносит.

Управление (MVP): вперёд/назад, стрейф, вверх/вниз, обзор мышью, укус, заглушка Sense.

---

## 6. Кровь

Кровь — не счётчик «очков победы».

- Добывается укусом взрослого.
- Тратится на жизнь.
- Нужна для яиц и улучшений (с 0.3).
- Нельзя бесконечно пить без риска: каждый укус поднимает раздражение.

Разные типы людей (спортсмен, пожилой, после спорта, в репелленте) и «вкусы» групп крови — после того, как один тип взрослого уже работает.

---

## 7. Человек — состояния

Не манекен с таймером поворота. Состояние по раздражению:

| Уровень | Состояние | Поведение |
| --- | --- | --- |
| 0 | Calm | занятие / простой idle |
| 1 | Noticed | «чёрт, комар»; может хлопнуть |
| 2 | Irritated | чешется, чаще машет |
| 3 | Angry | ищет комара |
| 4 | Rage / Chase | бросает занятие, охотится |

Источники раздражения: укус, близость, громкое жужжание у головы.

Если комар далеко — раздражение медленно падает.

**Способы борьбы (MVP):** хлопок рукой + воздушная волна, которая сносит комара.

Позже: полотенце, распылитель, мухобойка, тапок, закрытие окон, фумигатор, ловушки.

---

## 8. AI людей (MVP vs позже)

**MVP**

- Стоит / медленно ходит по короткому маршруту.
- Детект: радиус + шум + видимость (можно начать с радиуса + noise).
- Поворот к комару, хлопок, при Chase — движение к позиции комара (без сложного navmesh, прямой путь ок).

**Позже**

- Расписание на сутки (сон, сад, еда, терраса).
- Разные занятия днём и ночью.
- Закрытие окон, зов второго человека, предсказание полёта.

---

## 9. Посадка и укус

1. Комар близко к телу человека.
2. Посадка (действие укуса / land).
3. Короткая уязвимая фаза (0.5–1 с).
4. +Blood, человек получает OnBitten → раздражение++.
5. Можно сорваться и улететь.

---

## 10. Погоня

Отдельная мини-игра риска, не «случайный combat».

- Вход: Rage.
- Человек пытается убить комара.
- Время в погоне = награда (пример: 10 с → 10, 30 с → 50, 60 с → 150, 120 с → 500).
- Выход: комар потерян → Chase Complete.

В 0.1 достаточно: Chase + атака + воздушная волна. Очки и эскалация (мухобойка, второй человек) — 0.2.

Фирменный риск: специально жужжать у уха, чтобы ускорить ярость.

---

## 11. Стелс и Mosquito Sense

Три канала: **Noise**, **Visibility**, **Scent/Heat**.

**Mosquito Sense** (можно заглушка в 0.1): мир по CO₂ / теплу / запаху, поиск жертвы без прямой видимости.

Ночью светлая комната опаснее тёмной. Днём людей больше снаружи и комара легче заметить.

---

## 12. День / ночь

Обязательно уже в 0.1: вращение солнца, смена света, игровое время 0–24.

Модификаторы:

- День: активность людей, выше шанс быть увиденным.
- Ночь: люди в домах / спят, охота проще, позже — ночные хищники.

Длина суток в MVP короткая (например 2–5 минут = сутки) для проверки цикла.

---

## 13. Смерть и поколения

**0.1:** Health/крылья = 0 → смерть → короткое сообщение → respawn. Поколения ещё нет.

**Целевая модель:** комар гибнет → линия продолжается потомством → новый комар наследует часть генов. Не «game over с нуля».

Игрок — самка. Кровь → яйца → место кладки (вода) → личинки → поколение с выбором уклона (скорость, скрытность, запас крови, укус, устойчивость к ветру).

---

## 14. Мир, вода, погода, хищники

Не в 0.1, но зафиксировано, чтобы не ломать дизайн:

- Вода (лужа, ведро, бочка, бассейн…) нужна для кладки; дождь создаёт новые места.
- Ветер сносит маленького комара.
- Паук создаёт зоны страха (паутина), не просто «ещё моб».
- Остальные хищники по одному, не пачкой.

Дома: улица → окно (открыто / закрыто / сетка) → комнаты. Свет меняет видимость.

---

## 15. Две стратегии

Один и тот же NPC даёт разный геймплей:

**Тихий комар:** скрытность → посадка → укус → уйти.

**Комар-террорист:** жужжание → укусы → ярость → погоня → выжить → награда.

---

## 16. MVP 0.1 — Definition of Done

Игрок может запустить игру и пройти цикл:

1. Управлять комаром в полёте с камерой.
2. Летать по маленькому двору с 1 домом (примитивы ок).
3. Найти 2–3 взрослых NPC.
4. Подлететь, сесть, укусить, получить кровь.
5. Вызвать цепочку раздражения вплоть до попытки убийства.
6. Быть снесённым хлопком / получить урон крыльев.
7. Видеть базовый HUD (кровь, энергия, здоровье, время суток).
8. Умереть и респавниться (без генетики).

**Вне 0.1:** посёлок, расписания, погода, пауки, поколения, экипировка, фракции, фонд, цивилизация, группы крови.

---

## 17. Версии после MVP

- **0.2** — погоня с очками, паук, сейв, UI, простая прокачка.
- **0.3** — яйца, вода, поколения, гены.
- **0.4** — посёлок, расписания, дома, погода, ветер, ещё хищники.
- **0.5+** — экипировка, комариные NPC, юмор, задания, районы.
